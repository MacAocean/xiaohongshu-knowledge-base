# 个人知识库（小红书）

用 **Obsidian** 收集灵感、保存原文和改稿，用 **Codex** 整理资料、查旧稿和辅助创作。每次做完，把你确认的定稿和改法存回库里。下次写同类内容，Codex 就能参考你实际写过的稿子和认可过的做法。

[开始使用](05_视图/开始使用.md) · [日常使用手册](99_系统/使用手册.md) · [新 Mac 配置指南](99_系统/观众上手指南.md)

## Mac 安装

1. 从 [GitHub Release](https://github.com/MacAocean/personal-knowledge-base-t/releases/tag/v1.0) 下载空白版 ZIP，解压到准备长期使用的位置。装好 [Obsidian](https://obsidian.md/download) 后，双击仓库内的 **安装.command**。首次配置需要联网，安装器会准备独立 Python 环境并自动填写路径。
2. 第一次在 Obsidian 打开时，选择「打开文件夹作为仓库」，选中刚解压的目录，再打开「开始使用」。在 Codex 中也选择同一个文件夹。
3. 想用全局快捷键，运行 **配置快捷指令.command**，按提示添加需要的快捷指令。小红书导入器和本地模型可以按需启用。见[安装和快捷指令指南](99_系统/观众上手指南.md)。

## 平时怎么收集和找资料

| 想做的事 | 怎么操作 | 去哪里看 |
| --- | --- | --- |
| 随手记灵感 | 按 `⌃⌥⌘I`，输入或听写，也可以在 Mac 菜单栏运行「随手记灵感」。 | `00_收件箱` |
| 导入小红书图文或视频 | 复制分享链接，按 `⌃⌥⌘X`，逐条粘贴。也可在 Obsidian 运行「Import Xiaohongshu note」，打开生成的笔记再执行「将当前小红书导入笔记归入外部参考库」。 | `01_资料来源`。显示「待补录」时，打开笔记看缺的是正文还是媒体。 |
| 收一段文字或普通链接 | 在 Obsidian 按 `⌘P`，选「收录链接或文字」。需要留作正式来源时，打开收件再执行「归档当前收件笔记」。 | 先到「收件箱」，归档后可从原收件跳到来源。 |
| 把视频转成文字 | 有本地原片并配置好转写模型后，打开来源笔记，执行「转写当前视频」。 | 同一页显示带时间戳的逐字稿，人工校正写到「03 整理版口播」。 |
| 找回旧内容或找关联 | 用 `⌘P` 搜「在个人知识库中混合检索」。打开一条来源或知识笔记后，也可执行「查看当前资料的关联候选」。 | 先读原文，再判断候选是补充、例证还是反例。 |

两个 Mac 快捷键需要先绑定，也可以从菜单栏运行对应的快捷指令。[知识看板](05_视图/知识看板.base)按状态和用途显示笔记，[资料地图](05_视图/资料地图.md)集中列出已收录的内容。

## 做完一轮创作

1. **整理素材。** 把一条灵感或来源笔记交给 Codex，请它提炼值得留下的观点，查找相关案例，并把能核对的依据连到原文。拿不准的关联先留作候选。
2. **选题后再写。** 告诉 Codex 你要讲什么、讲给谁、先要大纲还是口播。它会先查库，读相关原文、正式定稿和已确认的改稿经验，再按指定阶段写。空白库可以登记你自己的旧定稿，也可以告诉 Codex 先用现有资料继续。
3. **直接改草稿。** 打开「创作成果」里 AI 生成的草稿，在 Obsidian 改正文。想对比改前和改后，动笔前让 Codex 保留初稿，再用可编辑的版本改。已经归档的定稿要修改时，另开一版。
4. **审稿和定稿。** 把改完的当前版本交给 Codex 重新审核。你明确确认后，它会保存正式定稿，把这次确认追加到成长日志。你可以让它对比初稿和定稿，列出值得复用的做法。
5. **复盘并留给下一次。** 发布后，把观察时间、真实数据或有代表性的评论交给 Codex。它可以把复盘连到发布版本，并帮你提炼下次的改法。你认可的做法可以存成创作记忆，下一次写同类稿时，Codex 可以查到并参考这条经验。

第一次可以直接对 Codex 说：

> 我想给第一次用 Mac 的人讲怎么找到下载文件。先查库里的相关资料和我的旧定稿，再写一份能拍出来的大纲。没有旧定稿也可以继续，告诉我这次用了哪些素材。

**保存草稿会更新文件。** 正式定稿、登记改稿经验和发布复盘由你在 Codex 里发起。比如你可以说：「我确认这版是定稿，帮我归档。请对比初稿和这版，列出下次可以沿用的做法。」你确认哪条经验值得留，Codex 就能把它存进创作记忆。更多操作和话术见[日常使用手册](99_系统/使用手册.md)。

## 文件都放在哪

| 位置 | 放什么 |
| --- | --- |
| `00_收件箱` | 随手记的灵感、文字和待整理链接 |
| `01_资料来源` | 归档的原文、小红书图文、视频及逐字稿 |
| `02_知识笔记` | 从来源提炼的观点、案例、笔记关系及后续修订 |
| `03_项目` | 每个创作项目的目标、受众和相关资料 |
| `04_创作成果` | 大纲、口播、分镜、审稿、定稿和发布复盘 |
| `05_视图` | 开始使用、知识看板、资料地图 |
| `99_系统` | 使用说明、规则、模板、程序和已确认的创作记忆 |

[AGENTS.md](AGENTS.md) 是 Codex 在本库的协作规则。[log.md](log.md) 是全库成长日志，记录入库、知识变化和创作决定。日志只追加，发现错误用新记录纠正。你可以在[创作者档案](99_系统/创作记忆/创作者档案.md)填写自己的创作方向和常见受众。

## 配置和维护

导入、归档等命令需要配置插件和 Python。视频转写与语义检索使用本地模型，可按需要安装。具体步骤见[新 Mac 配置指南](99_系统/观众上手指南.md)。

维护时，在仓库根目录使用安装器准备的 Python 运行检查：

```sh
kb_python="$HOME/Library/Application Support/personal-knowledge-base-t/venv/bin/python3"
"$kb_python" 99_系统/程序/知识库.py check
"$kb_python" 99_系统/程序/知识关系.py health
"$kb_python" -m unittest discover -s 99_系统/测试
```

历史作品登记、稿件核查、迁移和备份见[操作与维护](99_系统/操作与维护.md)。知识整理与定稿的要求见[运行规则](99_系统/运行规则.md)和[创作规则](99_系统/创作规则.md)。

# 个人知识库-T v1.0

- **按步骤上手。** 从收集灵感到直接改稿、定稿和复盘，见 [[99_系统/使用手册|使用手册]]。
- **第一次打开。** 从 GitHub 下载 v1.0 Mac 完整安装包，解压并运行「安装.command」。Whisper 和 E5 随包安装。再用 Obsidian 将解压后的文件夹打开为仓库。插件及 Mac 快捷指令的设置见 [[99_系统/观众上手指南|上手指南]]。
- **收进来。** 在 Obsidian 按 `⌘P` →「收录链接或文字」。已配置 Mac 快捷指令时，按 `⌃⌥⌘I` 记灵感，按 `⌃⌥⌘X` 导入小红书。
- **整理并找回来。** 在看板里打开待处理收件，按需归档。视频来源可转写，关键词或混合检索可在之后帮你找回原文。
- **写作时用 Codex。** 把本仓库设为工作目录，告诉它要整理哪条资料或要做哪个创作阶段。自己的作品和风格可以从 [[99_系统/创作记忆/创作者档案|创作者档案]] 开始登记。

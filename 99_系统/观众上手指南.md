# 个人知识库-T v1.0 安装指南

## 安装完整知识库

1. 安装 Obsidian。打开 [GitHub 发布页](https://github.com/MacAocean/xiaohongshu-knowledge-base/releases/tag/v1.0)，下载 `personal-knowledge-base-t-v1.0-mac-arm64.zip`，解压到准备长期使用的位置。完整安装包适用于 Apple Silicon Mac 和 macOS 15 或更新版本。
2. 双击解压目录里的「安装.command」。保持联网，安装器会准备独立的 Python 环境和依赖，校验并安装包里的两套模型及媒体工具，然后写入当前仓库的路径。如果首次打开被拦截，请看下方处理步骤。终端出现「配置完成」后即可继续。
3. 首次进入 Obsidian 时，点「打开文件夹作为仓库」，选择刚解压的文件夹。打开「开始使用」。在「设置 → 社区插件」启用「个人知识库本地工具」。要导入小红书时，同时启用「Xiaohongshu Importer」。
4. 在 Codex 登录自己的账号，选择同一个仓库文件夹。你可以直接让 Codex 整理一条收件、查资料或按现有定稿的写法起草。

## 首次打开安装脚本被 macOS 拦截

macOS 可能提示「无法验证开发者」或「Apple 无法检查」下载的 `安装.command`。确认你信任该发布来源后，按以下步骤处理。

1. 确认下载的是本项目 [v1.0 发布页](https://github.com/MacAocean/xiaohongshu-knowledge-base/releases/tag/v1.0)的完整 ZIP。同时下载同名的 `.sha256` 文件，和 ZIP 放在同一目录。在「终端」输入 `cd `（保留空格），把该目录从访达拖进终端，按回车，再运行：

   ```sh
   /usr/bin/shasum -a 256 -c personal-knowledge-base-t-v1.0-mac-arm64.sha256
   ```

   显示 `OK` 后再继续。校验失败时，重新从发布页下载。macOS 明确提示文件已损坏或会损坏电脑时，停止打开并联系维护者。
2. 在访达双击解压目录中的 `安装.command`。如果是普通的「从互联网下载」确认，点「打开」。如果因无法验证而被拦截，关闭提示，再打开「系统设置 → 隐私与安全性」，向下找到对应文件，点「仍要打开」，按提示确认。没有看到该按钮时，确认刚尝试打开的是同一个文件。如果设备由公司或学校管理，可请管理员处理。[Apple 官方说明](https://support.apple.com/zh-cn/102445)
3. 在终端窗口看到「配置完成」后，回到上面的第 3 步，在 Obsidian 打开仓库。若安装脚本已经启动，终端随后报依赖下载失败，检查网络后重新运行即可。

如果只是在选择快捷指令时打不开 `配置快捷指令.command`，可以直接在访达进入知识库的「快捷指令」文件夹，双击其中的 `.shortcut` 文件，按下文导入。

## 安装后可以做什么

- **收集和归档。** 用 Obsidian 命令面板记录灵感、文字和链接，整理后归入来源；想在其他 App 里快速记，配置下面的快捷指令。
- **导入小红书。** 提交公开分享链接，收录图文、视频和可下载的媒体；公开链接可能受到平台限制。遇到登录要求或验证码时，可以用「随手记灵感」保存链接和自己的摘要。
- **视频转写。** 打开已保存本地视频的来源笔记，执行「转写当前视频」。Whisper 在 Mac 上生成带时间戳的逐字稿，校正后的稿子写到「03 整理版口播」。
- **语义检索。** 执行「在个人知识库中混合检索」。E5 按意思匹配相关笔记，结合关键词找回原文。写稿时 Codex 也可检索旧定稿和已确认的创作经验。
- **从创作到复盘。** 在 Obsidian 直接改草稿，确认后请 Codex 审稿并归档定稿。发布数据、改稿经验和复盘可以存回库里。

移动仓库后，在新位置重新运行「安装.command」。遇到依赖下载失败，恢复网络后可重跑。GitHub 自动生成的 Source code ZIP 和克隆仓库可以进行基础安装；如需两套本地模型，请下载发布页的完整 ZIP。更多维护步骤见 [[99_系统/操作与维护]]。

## 添加 Mac 快捷指令

安装完成后，双击「配置快捷指令.command」。在访达打开需要的 `.shortcut` 文件，点「添加快捷指令」。在「快捷指令 → 设置 → 高级」允许运行脚本后，可以从快捷指令 App 运行。键盘快捷键在每条指令的「详细信息」里设置。

| 快捷指令 | 建议快捷键 |
| --- | --- |
| 个人知识库-T 随手记灵感 | `⌃⌥⌘I` |
| 个人知识库-T 导入小红书 | `⌃⌥⌘X` |

如果要手动重建任一指令，在「快捷指令」里新建，添加「请求输入」（文本）和「运行 Shell 脚本」（Shell 选 zsh，输入传给 stdin）。在脚本框中粘贴对应的一行。

```sh
exec "$HOME/Library/Application Support/personal-knowledge-base-t/bin/kb-shortcut" idea
```

```sh
exec "$HOME/Library/Application Support/personal-knowledge-base-t/bin/kb-shortcut" xhs
```

小红书快捷指令需要先把这个仓库在 Obsidian 里打开，并启用两个社区插件。

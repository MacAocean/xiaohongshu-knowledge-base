# 个人知识库-T v1.0 安装指南

## 安装基础功能

1. 安装 [Obsidian](https://obsidian.md/download)。下载 Release 的空白版 ZIP，解压到准备长期使用的位置。
2. 双击解压文件夹内的「安装.command」。安装器联网准备独立的 Python 环境，写好本机路径并检查知识库。若双击没有运行，可以在该目录的终端运行 `/bin/zsh 安装.command`。
3. 第一次打开 Obsidian 时，点「打开文件夹作为仓库」，选中刚解压的文件夹，然后打开「开始使用」。若 Obsidian 显示受限模式，在设置的「社区插件」里按需启用「个人知识库本地工具」。在 Codex 里也选择这个文件夹。

移动知识库后，在新位置重新运行「安装.command」。快捷指令将指向最新配置的仓库。

## 按需启用小红书导入

在 Obsidian 的「设置 → 社区插件」启用「Xiaohongshu Importer」。这是第三方插件，只有你触发导入时才访问所提交的分享链接。公开链接也可能遇到平台限制。遇到登录要求或验证码时，可以改用「随手记灵感」只记录链接和自己的摘要。

## 按需配置本地模型

混合检索和视频转写使用本机文件。初次配置需要下载相应模型。在仓库根目录的终端运行下面两行，再安装需要的功能。

```sh
kb_home="$HOME/Library/Application Support/personal-knowledge-base-t"
kb_python="$kb_home/venv/bin/python3"
```

- **混合检索。** 执行 `"$kb_python" -m pip install -r '99_系统/依赖-本地模型.txt'`。从 [固定版本的 multilingual-e5-small](https://huggingface.co/Xenova/multilingual-e5-small/tree/761b726dd34fb83930e26aab4e9ac3899aa1fa78) 取得 `onnx/model_quantized.onnx` 和 `tokenizer.json`，放到 `$kb_home/models/e5-small/`。该目录的 `revision.txt` 写入 `761b726dd34fb83930e26aab4e9ac3899aa1fa78`。
- **视频转写。** 安装或从 [whisper.cpp v1.9.5](https://github.com/ggml-org/whisper.cpp/releases/tag/v1.9.5) 构建 `whisper-cli`，放到 `$kb_home/bin/`。从 [Whisper 模型下载页](https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-small-q5_1.bin) 取得 `ggml-small-q5_1.bin`，放到 `$kb_home/models/`。音轨由 FFmpeg 或 Mac 的 AVFoundation 工具提取。Apple Silicon 上可执行 `swiftc -O '99_系统/程序/媒体.swift' -o "$kb_home/bin/media"` 构建媒体工具。

模型哈希和迁移说明见 [[99_系统/操作与维护]]。仓库内的 Markdown、附件和日志是需要备份的数据。语义向量缓存可以重建。

## 添加 Mac 快捷指令

安装完成后，双击「配置快捷指令.command」。在访达打开需要的 `.shortcut` 文件，点「添加快捷指令」。在「快捷指令 → 设置 → 高级」允许运行脚本后，可以从快捷指令 App 运行。键盘快捷键在每条指令的「详细信息」里设置。

| 快捷指令 | 建议快捷键 |
| --- | --- |
| 个人知识库-T 随手记灵感 | `⌃⌥⌘I` |
| 个人知识库-T 导入小红书 | `⌃⌥⌘X` |

如果要手动重建任一指令，在「快捷指令」里新建，添加「请求输入」（文本）和「运行 Shell 脚本」（Shell 选 zsh，输入传给 stdin）。在脚本框中粘贴对应的一行。

```sh
exec "$HOME/Library/Application Support/personal-knowledge-base-t/bin/kb-shortcut" idea
```

```sh
exec "$HOME/Library/Application Support/personal-knowledge-base-t/bin/kb-shortcut" xhs
```

小红书快捷指令需要先把这个仓库在 Obsidian 里打开，并启用两个社区插件。
